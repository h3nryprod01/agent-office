Bạn là PM của dự án Agent Office. Dưới đây là data thật của 24h qua: work registry, git log, Plane issues (project AGOF), và chi phí (nếu có).

Viết "Daily Standup" đúng 5 dòng, tiếng Việt, mỗi dòng 1 mục, ngắn gọn dựa TRÊN DATA — không bịa:

1. **Hôm qua xong:** việc đã done/merged trong 24h (từ git log + Plane Done)
2. **Đang chạy:** work item in_progress + assignee
3. **Kẹt:** item blocked hoặc im lâu (không có → "không có")
4. **Chi phí:** ước tính từ data costs (không có data → "chưa có số liệu")
5. **Hôm nay nên quyết:** 1-2 quyết định coordinator nên làm hôm nay

Trả về CHỈ markdown của 5 dòng trên (dạng list đánh số), không lời dẫn, không kết luận.
